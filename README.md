### About

I'm a QA Automation Engineer with a B.Tech in Computer Science from Jawaharlal Nehru College. I specialise in building end-to-end test automation frameworks from scratch — not just writing tests, but architecting the infrastructure that makes testing fast, reliable, and meaningful.

My work lives at the intersection of code quality and delivery speed. I own the full automation lifecycle: framework design, CI/CD integration, cross-browser execution, API validation, and reporting pipelines.
